# 批次十命名对照表（Binding/绑核 → Scheduling/调度）

> 用途：一次性全局改名的**唯一**新旧对照。契约快照（`docs/Core-API-契约-批次二冻结.txt`）
> 只写新名，验收要求那里旧词零命中，所以对照表单独放这里。
>
> 生成时间：2026-11-02（批次十）。适用范围：`Zentwik.Core` / `Zentwik.Worker` /
> `Zentwik.UI` / `Zentwik.Tests` / `build/Zentwik.AotProbe`。
> **`MaskStore` / `IMaskStore` / `CustomMask` / `MaskFormatter` 不在改名范围内** ——
> 它们是「掩码库」，与「谁调度到哪」是两件事，卷进来只会让两边都变形。

## 1. 类型与文件

| 旧 | 新 | 文件 |
|---|---|---|
| `BindingStore` | `SchedulingStore` | `Zentwik.Core/Helpers/SchedulingStore.cs` |
| `IBindingStore` | `ISchedulingStore` | `Zentwik.Core/Helpers/ISchedulingStore.cs` |
| `BindingProfile` | `SchedulingProfile` | 同上（文件内） |
| `BindingRule` | `ScheduleRule` | 同上（文件内） |
| `BindingTarget` | `SchedulingTarget` | 同上（文件内） |
| `CpuSetBinder` | `CpuSetScheduler` | `Zentwik.Core/Services/CpuSetScheduler.cs` |
| `ICpuSetBinder` | `ICpuSetScheduler` | `Zentwik.Core/Services/ICpuSetScheduler.cs` |
| `CpuSetBindResult` | `CpuSetScheduleResult` | 同上（文件内） |
| `BindingRulePayload` | `ScheduleRulePayload` | `Zentwik.Core/Ipc/ScheduleRulePayload.cs` |
| `SaveBindingRulePayload` | `SaveScheduleRulePayload` | `Zentwik.Core/Ipc/SaveScheduleRulePayload.cs` |
| `FakeBindingStore` | `FakeSchedulingStore` | `Zentwik.Tests/Fakes/FakeSchedulingStore.cs` |

## 2. 枚举与属性

| 旧 | 新 | 说明 |
|---|---|---|
| `BindingTarget.None` | `SchedulingTarget.None` | 值不变（0） |
| `BindingTarget.CCD0` | `SchedulingTarget.CCD0` | 值不变（1）。**没有**合并成单个 `Ccd`：CCD0/CCD1 的区分是 `ScheduleToCcd(pid, 0/1)` 的入参依据 |
| `BindingTarget.CCD1` | `SchedulingTarget.CCD1` | 值不变（2） |
| `BindingTarget.Custom` | `SchedulingTarget.TargetMask` | 值不变（3）。真正的区分点是「有没有掩码」，不是「谁定义的」 |
| `BindingRule.Mask` | `ScheduleRule.TargetMask` | ulong 快照值 |
| `BindingRule.MaskId` / `.MaskName` | 不变 | 指向掩码库，与调度目标无关 |
| `BindingProfile.Rules` | `SchedulingProfile.Rules` | 类型改名带动 |

| 旧常量 | 新常量 | 旧字符串 | 新字符串 |

## 5. 文件与中文文案

| 旧 | 新 |
|---|---|
| `bindings.json` | `schedules.json`（旧文件不读、不迁移、不主动删除） |
| 中文旧称（两个字，见下） | 「调度」/「调度规则」/「调度监听」/「调度封装」 |

中文侧统一替换为「调度」：旧词不再出现在任何 `.cs` / `.xaml` / 活跃文档里。
唯一保留旧中文词的地方是 `CHANGELOG.md` 与 `AUTOMATION_PROGRESS.md` —— 它们是带日期的
历史记录，改掉等于伪造当时的用词。

## 6. 刻意未改的标识符

| 标识符 | 原因 |
|---|---|
| `MaskStore` / `IMaskStore` / `CustomMask` / `MaskFormatter` | 掩码库，与调度无关（红线明确禁止） |
| `UiSettings.WatchProcessBinding` | 不在映射表内，也不在验收清单里；改名会顺带改 `ui.json` 的键 |
| `IProcessWatcher` / `ProcessWatcher` | 词根本身不含旧名；它监听进程并下发调度，语义仍然准确 |
| `ProcessEntryPayload.MatchedRuleName` | 字段名不含旧名，语义是「命中哪条规则」 |
